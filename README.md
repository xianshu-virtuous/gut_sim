# 肠胃模拟（gut_sim）

给角色装一条会累、会憋、会出事的肠胃。

它默认**只是一个安静的模拟器**：两条数值随聊天慢慢涨，涨到「有感」「强烈」时写一句身体感受进提示词。
失禁、羞耻干扰这些猎奇部分全部是独立开关，想让角色多狼狈，由你自己往上开。

> 娱乐向功能插件，纯虚构描写。不涉及现实医疗建议。

---

## 它做什么

- **两条数值**：屁意（gas）与便意（stool），各自有上限，各自按轮次与 token 推进；屁意跑得更快。
- **三档感受**：0~60 无感 / 61~90 有感 / 90+ 强烈。档位决定提示词里写多少、写多急。
- **憋忍经验**：忍着会积累经验，升级时两条上限一起涨（初始 100，最高 300）。
- **羞耻值**：越高越憋不住（溢出容差变小）、聊天时越狼狈（可选的干扰约束）。
- **状态事件**：4 种负面（羞耻心爆棚 / 胀气 / 闹肚子 / 肠胃弱化）+ 3 种正面（安心 / 肠胃强化 / 舒畅），
  由便宜模型按聊天语境判断该不该附加，判断放在后台，不拖慢回复。
- **和 sisp 联动**：检测到角色处于 sisp 的私密模式时，按便意档位告诉它「现在是什么感觉」。

## 数值一览

| 项 | 便意 | 屁意 |
|---|---|---|
| 初始上限 | 100 | 100 |
| 成长上限 | 300 | 300 |
| 奖励上限 | +10（羞耻低）+10（强化） | +10（羞耻低） |
| 理论极限 | 320 | 310 |
| 增速 | 每轮 1.5 + token/250 | 便意增速 × `gas_ratio`（2.0~3.0） |

- 档位阈值是**绝对点**（60 / 90），与上限无关：上限涨起来后，「强烈」这一段会很长。
- 溢出容差：羞耻 0~30 → 10 点；31~60 → 6 点；61~100 → 2 点。超过「上限 + 容差」才出事。
- 失禁/漏气后两条归零；漏气加的羞耻少，便意失禁加得多。

## 猎奇开关（默认全关）

| 开关 | 默认 | 开了会怎样 |
|---|---|---|
| `shame.wetting_enabled` | 关 | 便意越线 → 失禁，羞耻 +22 |
| `shame.leak_enabled` | 关 | 屁意越线 → 漏气，羞耻 +4 |
| `inject.disrupt_enabled` | 关 | 羞耻高档时要求短句、带音效、不主动展开 |

全关时：数值涨到上限就停住，不会出事——就是一条安静的模拟器。

## 与 sisp 的兼容

插件**只读** sisp 的状态文件，不改任何 sisp 代码：

| sisp 版本 | storage store | 私密字段 |
|---|---|---|
| 市场版 sisp | `sisp` | `in_sex_mode` |
| deep_neo_sisp | `deep_neo_sisp` | `in_sex_mode` |
| 本地改造版 | `sisp` | `in_sex_mode` |

探测顺序写在 `[sisp].store_order`，读不到就当作普通模式（日常只注入一句轻描述）。
没装 sisp 也能用——它就只是个日常肠胃模拟。

## 她还会自己溜去洗手间

不是命令，是**离线行为**（机制和上下文归档的巡检一样）：

1. 某条流安静够久（默认 15 分钟）→ 巡检按概率把她送去洗手间，待 1~4 分钟；
2. 这期间来了消息 → **消息被压 3~4 秒**再处理（模拟她伸手拦了一下、让你等一下）；
3. 回来 → 两条数值清空；被问起就如实说"刚才去洗手间了"。

**作用域（默认偏保守）**

| 场景 | 默认行为 |
|---|---|
| 私聊 · 白名单内 | 会触发，被问起直说去上厕所 |
| 私聊 · 白名单外 | 不触发（可以关掉 `private_whitelist_only` 放开） |
| 群聊 | 默认不触发；真开了也用隐晦说法（"去了一下洗手间"） |

白名单在 `[toilet].whitelist` 里填 `sender_id`（QQ 号）。

## 和其他插件的关系

| 插件 | 关系 | 怎么联动 |
|---|---|---|
| **sisp / deep_neo_sisp** | 只读，不改对方代码 | 读 `in_sex_mode` 决定注入口吻；读 `scene` / `scene_until` 点亮同名事件卡 |
| **daily_schedule** | 软依赖，没有也能跑 | 如厕回来 / 失禁时向当天日程日志注入一条约 10 分钟的事件 |

日程联动的写法是**软依赖**：manifest 里不声明（声明了会被静默剔除），运行时才尝试 import，
拿不到就静默跳过，写失败也不影响对话。

## 命令

- `/肠胃` —— 查看当前状态（两条数值、档位、憋忍等级、羞耻、是否私密模式）
- `/肠胃 上厕所` —— 立刻排空：两条归零、给两轮「舒畅」
- `/肠胃 reset` —— 清空当前流的数值（保留等级与抗性）

仅主人可用，回执不进入 LLM 上下文。

## 事件卡（场景卡）

结构和 sisp 的 `scene_cards.json` 对齐，所以两边说的是同一件事：

| 卡 id | 触发词（例） | 效果 |
|---|---|---|
| `laxative` 泻药 | 泻药 / 吃了药 / 开塞露 | 便意 ×2.5、屁意 ×1.3、上限 ×0.85 |
| `stomach_ache` 闹肚子 | 肚子疼 / 拉肚子 / 肚子不舒服 | 便意 ×1.6、屁意 ×1.5 |
| `gas_hold` 憋着气 | 憋着 / 不许放 / 忍着别放 | 屁意 ×2.0、上限 ×1.2 |
| `cold` 受凉 | 着凉 / 喝了冰 / 冰可乐 | 便意 ×1.8、屁意 ×1.4 |
| `banquet` 吃撑了 | 吃多了 / 火锅 / 自助 | 屁意 ×1.8、便意 ×1.4 |

- 卡里有 `place`（床上 / 沙发上 / 被窝里 / 出租车后座 / 餐桌旁），**失禁描述会落在那个场景里**。
- **跟随 sisp**：sisp 当前生效的场景标签如果和我们同名，会自动点亮我们的同名卡（`[scene].follow_sisp`）。
- 加卡/改卡：`[scene].custom_cards`，一项一个表（`id/title/triggers/hours/gas_mult/stool_mult/cap_mult/place/prompt`）。
- 手动：`/肠胃 卡` 看当前卡，`/肠胃 卡 off` 关掉。

## 满值之后会怎样

默认配置下，两条数值到上限就**停住不动**（既不增长也不出事）。如果觉得这样太假：

| 配置 | 效果 |
|---|---|
| `numeric.passive_vent = 2` | 屁意到顶后每轮自己漏 2 点，像气球慢慢漏气，不加羞耻 |
| `shame.leak_enabled = true` | 屁意越线才**失禁式漏气**：归零 + 羞耻 +4（配合容差使用） |
| `shame.wetting_enabled = true` | 便意越线才失禁：归零 + 羞耻 +22 |

## 关键配置

配置文件：`config/plugins/gut_sim/config.toml`（首次加载自动生成）

```toml
[numeric]
base_rate = 1.5      # 便意每轮基础增量
gas_ratio = 2.5      # 屁意倍速（人设推断会覆盖一次，之后以这里为准）
token_div = 250.0    # token 加成除数，填 0 = 只看轮次
tier_1 = 60.0        # 有感线
tier_2 = 90.0        # 强烈线

[grow]
exp_per_level = 20   # 升一级要多少经验
cap_per_level = 10   # 每级两条上限各 +10

[shame]
wetting_enabled = false   # 猎奇总闸，默认关
disrupt_from_band = 60.0  # 羞耻到多少开始干扰

[inject]
normal_inject_min_tier = 2  # 普通模式到几档才注入（默认二档，一档不占 token）
```

## 首次加载

第一次加载会读 `core.toml` 的 `[personality]`，调一次便宜模型推断：

- 易羞 / 不易羞（影响羞耻增长）
- 肠胃底子（影响事件倾向）
- `gas_ratio`（爱喝酒、不拘小节的偏高，敏感肠胃的偏低）

推断结果存在 `data/json_storage/gut_sim/profile.json`，不会被反复调用。
推断失败会随机落档并写日志，不会让插件起不来。

## 安装

把插件目录放进 `plugins/gut_sim/`（或安装 `.mfp`），重启即可。
